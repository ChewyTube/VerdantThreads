### 1.2 设计要点

- **分解入口**：手持右键（选中豌豆荚时）或背包窗右键豌豆荚行，共用 `Backpack.DecomposePeaPod`
- **产物**：4~8 粒豌豆粒（`ItemType.PeaSeed`），携带母本基因组 + 采收基因 HTT 载荷（种植继承采收潜力）
- **去向**：优先存入种子袋（按容量逐个填充），无种子袋/满则落入背包
- **豌豆粒可种植**：`PlaceableBlockType = PeaStem`，种植时建 tile（继承基因 + 采收基因），消耗 1 粒
- **堆叠**：豌豆粒按子集表型标签 {0,1}（子叶色+种子形状，与图标一致）分组合并，上限 64
- **种子袋取出**：子面板每行「取出」按钮，按基因型整组取出落背包（种子袋只存 Genome 计数，不含采收基因载荷——取出的种子采收基因回落到默认基线，已注释说明）

### 1.3 顺带修复的存档缺口（Phase 2 遗留）

- `BackpackSaver.ReadSlot` 原逻辑：携带基因物品一律用 genome 构造器重算**全量**表型标签 → 豌豆荚（子集 {3,4}）重启后标签数不同 → `CanMergeWith` 恒 false → 堆叠分组失效。现改为读回存档时的子集标签覆盖重算结果（豌豆荚/豌豆粒均受益）

### 1.4 验证

- 无 CLI 构建/测试（Unity 项目惯例），以代码一致性审查验证：新 API 使用点 grep 齐全（DecomposePeaPod/AddPeaSeeds/TakeFromSlot/GetHarvestGenome）、构造器重载无歧义、槽扣减索引修正逻辑推演（移除槽在选中前/选中/之后三种情况）、存档读写对称（WriteSlot 写子集标签 ↔ ReadSlot 读回覆盖）
- 遗留提示（非阻断）：种子袋内种子不含采收基因载荷（数据结构限制，如需继承需升级 SeedBag 存储模型）
