### 3. HTT 设计定案（玩家认可）

- 层级标签树（Hierarchical Tag Tree）：9 种 tag 类型（End/Byte/Short/Int/Long/String/ByteArray/List/Compound），Compound 命名子节点（键唯一）+ List 同构元素
- 大端二进制格式；防御校验（深度 ≤32、名字 ≤255、String ≤32KB、ByteArray ≤1MB、List ≤65536，失败回退基线仅日志警告）
- 线程纪律：HTT 树主线程独享，worker 只搬运字节（`TileSaveRecord.PayloadBytes`），反序列化在主线程
- 集成：vrf v4（tile 记录追加 payloadLen + payload，**空载荷不写段** → 旧档与基线株天然同构）+ BPK1 v2 + `PeaTileData.Payload` + `ItemInstance.Payload` + `HarvestGenome`（uint32 8 位点）+ `PeaHarvestCalculator`（次数 `min(2^(1+k),64)`；产量 阶段4 `12+2k` / 阶段3 `3+k`）
- 归档：`docs/design/HTT.md` 新建
