### 3. 豌豆采收系统设计协商

与玩家通过 5 轮问答协商全部设计细节：

| 决策点 | 结论 |
|--------|------|
| 阶段3采收 | 3~5 个**青嫩豆荚**（无基因，不可种，分表型） |
| 阶段4采收 | 12~16 个**豌豆荚**（带母本 Genome，可分解） |
| 物品类型 | 新增独立 `ItemType` 枚举，`ItemInstance` 持 `ItemType` + 可选 `PlaceableBlockType` |
| 堆叠规则 | 上限 64，**按表型合并**（同名+同可见性状），内部记录不同基因型各自数量 |
| 种子袋 | 独立物品，右键打开，上限 1024 粒豌豆（按基因型拆分显示） |
| 背包存档 | `BackpackSaver` → `world_saves/backpack.dat` |
| 分解 | 本期不做，预留接口（合成窗口 / 手持右键 → 4~8 粒/荚） |
| 初始种子 | 保持现状（背包第7格「豌豆种子」，无基因，种出随机基因） |
