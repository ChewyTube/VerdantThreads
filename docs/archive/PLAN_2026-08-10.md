## 任务二：P3-2 状态位运算符优先级 bug

### 现状（`Block.cs:49`）
```csharp
public uint GetBlockState() => _value & BlockBits.StateMask >> BlockBits.StateShift;
```
`&` 优先级低于 `>>`，实际解析为 `_value & (0x000F_0000 >> 16)` = `_value & 0xF`（取类型低 4 位），不是状态位。

### 改动
```csharp
public uint GetBlockState() => (_value & BlockBits.StateMask) >> BlockBits.StateShift;
```
- 函数目前**无调用方**，零行为影响；修好为将来"方块状态位"功能（如方向、生长阶段）铺路
- 顺手建议：加中文注释说明 StateMask=0x000F_0000、shift 16（`BlockBits.cs:58-59` 已有常量）

### 验证
- 编译通过即可（无调用方，行为不变）

## 任务三：P3-3 方向语义（最有价值，需要你决策）

### 侦察结论（方向语义错配实锤）
| 位置 | 语义 |
|---|---|
| `VoxelChunk.cs:242-250` `Direction` 枚举 | `North=5` 注释 +Z；`South=4` 注释 -Z |
| `BlockUVMap.cs:10-11` `FaceIndex` 常量 | `South=4` 注释 **+Z**；`North=5` 注释 **-Z** |
| `MeshData.cs:38-47` `FaceNormals` | 按 Direction 语义（North=+Z）✓ 正确 |

**错配点**：`MeshData.cs:73` `GetUVOffset(blockType, (int)dir)`——把 Direction 数值直接当 faceIndex 查 `BlockUVSet.GetUV`（`BlockUVMap.cs:34` `_uvs[faceIndex]`）。槽位顺序 `east, west, up, down, south, north`（:27-30）按 **FaceIndex 语义**（south 槽=+Z）。

结果：**+Z 面（Direction.North=5）取到的是 north 槽（标注 -Z）**。当前所有 side 槽纹理相同（`BlockUVSet` 三参构造 `(side,side,top,buttom,side,side)`，:20），所以肉眼不可见——**做方向性纹理（树皮、泥土侧壁、豆荚朝向）必炸**。

### 方案 A（推荐，最小改动，现在做）
`MeshData.cs` 加显式映射，替换 `(int)dir`：
```csharp
// Direction 语义（North=+Z）→ FaceIndex 槽位（south 槽=+Z）显式映射
private static int DirectionToFaceIndex(Direction dir) => dir switch
{
    Direction.East  => FaceIndex.East,   // 0
    Direction.West  => FaceIndex.West,   // 1
    Direction.Up    => FaceIndex.Up,     // 2
    Direction.Down  => FaceIndex.Down,   // 3
    Direction.South => FaceIndex.North,  // -Z 面 → north 槽（-Z）
    Direction.North => FaceIndex.South,  // +Z 面 → south 槽（+Z）
    _ => FaceIndex.Up,
};
```
- `GetUVOffset` 调用处（:73）改 `GetUVOffset(blockType, DirectionToFaceIndex(dir))`
- 行为不变（side 槽全同纹），但语义正确，方向性纹理可直接接入
- 顺带把 `FaceNormals` 与 `Direction` 枚举的注释统一（现在 `MeshData.cs:38` 注释已说明差异，保留即可）

### 方案 B（彻底，等方向性纹理需求时再做，今天不用做）
统一枚举：删掉 `VoxelChunk.Direction` 或 `FaceIndex` 之一，全项目用一套（推荐以 FaceIndex 常量 + Direction 语义合并为单一枚举）。牵动 `MeshData.GetFaceVertices`（:85-97）、`FaceNormals`（:39-47）、`ChunkMeshBuilder` 中的 Direction 用法——改动大、收益当前为 0，**建议推迟**。

### 验证（A）
- Play Mode 方块外观与之前完全一致
- 可选加分验证：临时给 Grass 加方向性侧壁纹理（把 `new(0,3)` 拆成不同槽位）确认朝向正确，验证后还原
