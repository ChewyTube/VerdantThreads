# VerdantThreads 游戏设计文档（GDD）

> **本文件是项目最高优先级的设计依据。** 所有功能开发与优先级决策都应回看此文档。
> 来源：玩家（项目作者）口述，2026-08-09 记录。

## 1. 游戏概述

- 类型：类《我的世界》（Minecraft-like）的体素世界游戏
- 引擎：Unity Tuanjie（团结引擎）
- 定位：**以孟德尔遗传定律等生物知识为核心，以体素世界为载体**构建的科技探索游戏

## 2. 玩家角色

玩家扮演一名**生物学家**，在游戏的引导与诱导下，完成从经典遗传学（孟德尔）到分子生物学（DNA / 基因编辑 / RNA 干扰）的科技探索之旅。

## 3. 核心循环

- 体素世界：探索与实验的载体（地形、采集、建造）
- 生物学知识：推动进程的核心机制
- 玩家通过在世界中的观察、实验、发现，逐步推进科技树直至通关

## 5. 玩法机制（作者零散想法汇总）

### 5.1 成就系统
- 获得具有**不同典型或极端性状**的生物后获得奖励
- 奖励用于**帮助推进科技树**（性状收集 → 驱动科技发展）

### 5.2 育种解密玩法
- 通过已有生物（**已知或未知基因型**）和**系谱图**，获得目标性状或基因型的生物
- 定位：类似解谜的核心玩法之一

### 5.3 碱基序列与性状的直接联系（通关段机制）
- 一条序列中包含不同的**密码子**，每个密码子编码一个**常数（参数）**
- 对**每个物种 × 每个基因**存在一个**损失函数**
- 将密码子编码出的参数代入损失函数，**损失越小，性状表现越佳**
- 即：碱基序列通过密码子参数化地（数值化）决定性状表现
